# Игровой сайт — мини-игры на JavaScript

Учебный проект с мини-играми на JavaScript.

## 🔗 Демо
[Посмотреть сайт](https://js-mini-games.netlify.app/)

## 📎 Портфолио
[Посмотреть все работы](https://your-finances.tilda.ws)

## 📋 Что реализовано
- **Викторина** — игра с вопросами и подсчётом очков
- **Мини-игры** — интерактивные задания
- **Эффекты наведения** — CSS-анимации
- **Анимированная линия** — декоративная полоса, которая движется
- **Адаптивная вёрстка** (десктоп / мобилка)

## 🛠️ Технологии
- HTML5
- CSS3
- JavaScript (ES6)
- DOM API

## 📁 Структура
- `index.html` — главная страница с играми
- `script.js` — основной скрипт
- `style.css` — стили
- `images/` — изображения
